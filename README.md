# Excel File Reader & Database Importer

A Spring Boot application that reads data from Excel files (`.xlsx`, `.xls`) and stores the extracted records into a relational database.

The application simplifies bulk data import by processing Excel files, validating records, and persisting data using Spring Data JPA.

## 🚀 Features

- Upload Excel files through REST APIs.
- Read `.xlsx` and `.xls` files.
- Extract Excel sheet data using Apache POI.
- Validate incoming records.
- Save extracted records into a database.
- Handle invalid or empty Excel files.
- RESTful API architecture.
- Exception handling and meaningful API responses.

|---|---|
